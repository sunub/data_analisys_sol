## 기존 보유 학원 자료의 상태

`2025년_12월_학원_현황.xlsx`는 남동구와 연수구만 포함한다.

- 교습과정 행: 남동구 10,047건, 연수구 13,164건
- 중복 제거 학원 수(`학원명 + 학원주소`): 남동구 829곳, 연수구 997곳
- 미추홀구 주소 행: 0건

따라서 이 파일만으로 세 구 사교육 인프라를 비교하면 안 된다.

## 확보가 필요한 자료

### 1. 세 구 공통 학원·교습소 원자료 — 필수

[전국 학원 및 교습소 표준데이터](https://www.data.go.kr/data/15096277/standard.do)는 인천광역시교육청을 필수 필터로 선택해 조회하도록 제공된다. 주소, 정원, 교습과정, 수강료 등의 필드를 포함한다.

수집 조건:

- 시도교육청: 인천광역시교육청
- 공간 필터: 남동구, 미추홀구, 연수구
- 동일 기준일·동일 열 정의로 세 구를 한 번에 추출
- 등록 상태와 수강료 공개 여부를 보존

현재 환경에서는 포털 선택형 다운로드가 인증·세션 조건으로 자동 완료되지 않았다. 다음 중 하나가 필요하다.

1. 포털에서 인천광역시교육청을 선택해 내려받은 CSV 제공
2. 교육정보 개방포털 API 활용 승인키 제공
3. 인천교육청의 같은 기준일 학원·교습소 파일 제공

### 2. 남동구·미추홀구 학교별 현황 — 필수

연수구와 동일하게 `학교 구분`, `학생 수`, `주소`, 가능하면 `위도·경도`가 있는 공개 파일을 확보한다. 인천교육청 전체 집계표로는 대체할 수 없다.

### 3. 다년도 인구·시설 자료 — 시계열 분석용

2025년 단면 비교는 가능하지만 인구 변화와 인프라의 동반 변화를 보려면 최소 2021~2025년의 같은 정의 자료가 필요하다. 연도 사이 행정동 명칭·주소 체계가 달라진 경우 원문과 표준화 값을 함께 보관한다.

### 4. 실제 이용과 학습지원 결과 — 교육의 질 판단용

현재 공개 자료에는 지역아동센터의 위치·정원·종사자만 있고, 실제 이용 아동 수·대기자·프로그램 참여율은 없다. 이 값은 인천시 또는 센터 운영기관에 구·동 단위 집계표로 요청한다.

기초학력 보장 사업의 시행계획은 공개되어 있으나, 세 구의 교육 질을 비교할 수 있는 기초학력 지원 대상 비율·지원 후 회복률은 공개 원자료에서 확인하지 못했다. 개인정보를 제외한 학교급·군구 단위의 집계값을 교육청에 요청한다.

## 사용 규칙

- `아동`과 `청소년`의 분모를 분리한다.
- 시설 수뿐 아니라 정원·종사자·교습과정을 병렬로 제시한다.
- 공시 교습비는 실제 가계 사교육비로 해석하지 않는다.
- 기준일이 12개월 이상 차이나면 직접적인 순위 비교를 만들지 않고, 각주에 시점 차이를 표시한다.
- 수급자 통계는 경제적 취약성의 보조 지표이며, 개별 가구 소득을 의미하지 않는다.
